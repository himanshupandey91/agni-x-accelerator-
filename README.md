# AGNI-X Accelerator

AGNI-X is an open technical research project exploring a high-efficiency AI accelerator architecture.

## Current Research Focus

- Low-voltage 0.55 V compute architecture
- MAC-based AI acceleration
- Tile-based architecture
- Memory hierarchy and interconnect
- Performance-per-watt analysis
- RTL simulation and reproducible validation

## Current Architecture Concept

AGNI-X v2.0 is currently documented as:

- 16 compute tiles
- 4,096 MACs per tile
- 65,536 total MACs
- 8-bit fixed-point multiplication
- 16-bit accumulation
- 0.55 V core operating target
- Hierarchical memory and Network-on-Chip architecture

## Repository Status

This repository is under active development.

The specifications and performance figures currently published here include architectural targets, simulations, and projections. They should not be interpreted as independently validated fabricated-silicon results unless explicitly marked as experimentally verified.
